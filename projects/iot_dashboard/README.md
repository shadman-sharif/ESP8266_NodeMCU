# 📊 IoT Dashboard

Starter folder for a larger ESP8266 monitoring project.

```text
Sensors
   ↓
ESP8266
   ↓
Wi-Fi
   ↓
HTTP / MQTT / API
   ↓
Dashboard
   ↓
Phone / Computer
```

Possible values:

- Temperature
- Humidity
- Light level
- Device uptime
- Wi-Fi signal strength
- Digital input status

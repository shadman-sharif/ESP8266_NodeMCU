# 🌡️ Temperature Monitor

Planned project structure for reading a temperature sensor and displaying its value through Wi-Fi.

```text
Temperature Sensor
       ↓
   ESP8266
       ↓
     Wi-Fi
       ↓
  Web Server
       ↓
   Phone / PC
```

Suggested development order:

1. Choose a supported sensor.
2. Verify voltage and wiring.
3. Read the sensor.
4. Print values to Serial Monitor.
5. Connect to Wi-Fi.
6. Display the value on a web page.
